Reading the Tier column

Flagship — the provider's most capable model, highest cost, best for tasks where getting it wrong is expensive.

Balanced — strong capability at a fraction of flagship cost; the right default for most applications.

Fast — optimized for speed and cost over raw capability; good for high-volume, low-stakes tasks.

Open-weight — you can download and run the model yourself instead of paying per token, at the cost of needing your own infrastructure (or a third-party host).

Raw benchmark scores are deliberately left out of this table — they go stale within weeks of a new release and are easy to misread out of context. Tier + context window + price is a more durable comparison for picking a model for a real project.
